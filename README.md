# Саяхатшы Балақайлар

Қазақстанның көрікті жерлеріне виртуалды саяхат. Сабақ: 4-сынып (орыс сыныбы), қазақ тілі.
Бағыт: Астана → Бурабай → Алматы.

Жоба толығымен браузерде жұмыс істейді: backend, дерекқор және авторизация жоқ.
Технологиялар: React, TypeScript, Vite, Tailwind, Framer Motion.

## Іске қосу

```bash
npm install
npm run dev      # әзірлеу режимі
npm run build    # dist/ — кез келген статикалық хостингке немесе офлайн көрсетуге
npm test         # балл, Word мазмұны және asset тесттері
```

## Құрылымы

| Жол | Не бар |
|---|---|
| `content/word-source.txt` | Word құжатының мәтіні — мазмұнның бірден-бір көзі |
| `src/content/lesson.ts` | Экрандағы оқу мәтіні. Әр жолы Word-та бар-жоғы тестпен тексеріледі |
| `src/game/tasks.ts` | Бағалау парағы (барлығы 10 балл) |
| `src/game/state.ts` | Орталық state (reducer) және оны localStorage-та сақтау |
| `src/assets/manifest.ts` | Asset Manifest. Сурет тек `<Asset id>` арқылы шығады |
| `src/screens/` | 16 экран. Қайсысы дайын екені `registry.ts`-те көрсетілген |
| `src/teacher/` | Мұғалім режимі |
| `scripts/` | Asset-терді өңдеу және браузерде тексеру (QA) скрипттері |

## Мұғалім режимі

Ашу үшін: `Shift + T` пернелері немесе экранның жоғарғы оң бұрышын 3 рет басу.

Мүмкіндіктері:
- кез келген экранға өту;
- үлгі жауапты көрсету;
- баллды қолмен қою;
- тапсырманы немесе бүкіл ойынды қайта бастау (reset).

## Жаңа asset қосу

1. Түпнұсқа файлды `asset-src/<asset-id>.png` деп сақтаңыз.
2. `python3 scripts/process_assets.py <asset-id>` командасын іске қосыңыз.
3. `manifest.ts` файлында осы asset-тің `status` мәнін `'final'` етіңіз.
